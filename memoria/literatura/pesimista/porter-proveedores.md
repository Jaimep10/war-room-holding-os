# El Poder de Negociación de los Proveedores — Michael Porter

## Idea central
Dentro de las 5 Fuerzas de Porter, el poder del proveedor mide cuánto puede un proveedor exprimir el margen del negocio (subiendo precio, bajando calidad, o limitando disponibilidad) sin perder al cliente.

## Cuándo el proveedor tiene mucho poder
- Hay pocos proveedores viables y muchos compradores (concentración de oferta).
- El costo de cambiar de proveedor es alto (contratos, certificación, curva de aprendizaje, inversión ya hecha).
- El proveedor no depende mucho de este comprador en particular (el comprador es pequeño para el proveedor).
- No hay sustituto razonable para lo que provee.
- El proveedor podría "integrarse hacia adelante" — volverse competidor directo vendiendo él mismo al cliente final.

## Cómo se reduce el poder del proveedor
- Multi-sourcing: calificar más de un proveedor viable, incluso si al inicio cuesta más.
- Aumentar el costo de cambio para el proveedor: ser un cliente grande y estratégico, no solo uno más.
- Integrar verticalmente si el volumen lo justifica.
- Contratos de largo plazo con condiciones de precio fijadas para blindarse de shocks de tipo de cambio o escasez.

## Uso en esta oficina
Cuando el Canvas de una idea muestra un solo proveedor o socio clave crítico, el Agente Pesimista debe tratarlo como una fuerza de Porter activa y cuantificar el riesgo (tiempo de reposición, % de dependencia, costo de cambio), no solo mencionarlo como una línea del Canvas.
