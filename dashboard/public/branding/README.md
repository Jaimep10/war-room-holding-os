# branding/

Acá van los archivos de identidad corporativa del cliente activo: logo,
paleta/tipografía si vienen como archivo, fotos reales del negocio.

`agente-web-wordpress` (ver `memoria/agentes/agente-web-wordpress.md`) le pide
esto al usuario en el chat antes de diseñar cualquier web — este es el lugar
real donde subirlo.

No se versiona el contenido subido acá (queda en `.gitignore`), solo esta
carpeta con este README para que el path exista.
